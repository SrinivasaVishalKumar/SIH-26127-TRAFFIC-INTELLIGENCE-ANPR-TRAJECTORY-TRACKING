# front_end_SIH127 — Traffic Intelligence Web Portal

Interactive web frontend for SIH-26127 Traffic Intelligence, providing real-time maps, vehicle search, analytics, and violation alerts.

## Features
- **Live ANPR Dashboard**: Real-time visualization of detected license plates
- **Spatial Map**: Trajectory visualization across city camera nodes
- **Vehicle Search**: Fast query interface for license plate lookups
- **Analytics Charts**: Traffic flow, speed violations, and density breakdowns

## How to Run
Simply open \index.html\ in any modern browser, or serve with a static server:
\\ash
# Using Python
python -m http.server 8000
\Then visit http://localhost:8000 in your browser.
